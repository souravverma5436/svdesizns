    git add -f "client/public/images/your image name.webp"

  Add MULTIPLE specific files:
    git add client/src/pages/Contact.jsx client/src/pages/Services.jsx

  Examples:

    git commit -m "fix: update contact page"

    git commit -m "update: services pricing updated"

  See commit history:
    git log --oneline

  Pull latest changes from GitHub to your PC:
    git pull origin main

  If push is rejected (remote has changes you don't have):
    git pull --rebase origin main

  Check which remote (GitHub URL) is connected:
    git remote -v

  See what branch you are on:
    git branch

  Undo last commit (keeps your file changes):
    git reset --soft HEAD~1

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  REQUIREMENTS — Install these first on the new system
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Node.js (version 18 or higher)
       Download from: https://nodejs.org
       After installing, verify with:
         node --version
         npm --version

  2. Git (optional but recommended)
       Download from: https://git-scm.com
       After installing, verify with:
         git --version

  3. A code editor (recommended: VS Code)
       Download from: https://code.visualstudio.com


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  METHOD 1 — You sent the project as a ZIP file
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  STEP 1: Extract the ZIP file anywhere on your system.
          Example: C:\Projects\sourav-portfolio

  STEP 2: Open PowerShell or Terminal and go to the client folder:
            cd C:\Projects\sourav-portfolio\client

  STEP 3: Install all required packages:
            npm install

          (This reads package.json and downloads everything needed)
          (Wait for it to finish — may take 1-2 minutes)

  STEP 4: Create the .env file (for EmailJS to work):
          Inside the client folder, create a file named:  .env
          Add this content inside it:

            VITE_EMAILJS_SERVICE_ID=your_service_id
            VITE_EMAILJS_TEMPLATE_ID=your_template_id
            VITE_EMAILJS_PUBLIC_KEY=your_public_key

          NOTE: Get these values from your EmailJS account at
                https://www.emailjs.com
                (Contact form will not send emails without this)

  STEP 5: Start the development server:
            npm run dev

  STEP 6: Open your browser and go to:
            http://localhost:5173

  Done! The website is now running locally.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  METHOD 2 — Clone directly from GitHub (recommended)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  STEP 1: Open PowerShell / Terminal on the new system.

  STEP 2: Go to the folder where you want to save the project:
            cd C:\Projects

  STEP 3: Clone the project from GitHub:
            git clone https://github.com/souravverma5436/svdesizns.git

  STEP 4: Go into the project folder:
            cd svdesizns

  STEP 5: Go into the client folder:
            cd client

  STEP 6: Install all packages:
            npm install

  STEP 7: Create the .env file (same as Method 1, Step 4 above)

  STEP 8: Start the dev server:
            npm run dev

  STEP 9: Open browser:
            http://localhost:5173

  ✔ NEVER share your .env file — it contains secret keys.
    The .env file is in .gitignore so it is NOT uploaded to GitHub.
    You must manually create it on every new system.

  ✔ The node_modules folder is also NOT shared (it is in .gitignore).
    Always run  npm install  after getting the project on a new system.

  ✔ If you see errors after npm install, try:
      npm install --legacy-peer-deps

  ✔ If port 5173 is busy, Vite will use 5174 or 5175 automatically.
    Check the terminal output to see the actual URL.

  ✔ To stop the development server: press  Ctrl + C  in the terminal.

  ✔ To build for production (creates deployable dist folder):
      npm run build

  ✔ To preview the production build locally:
      npm run preview
